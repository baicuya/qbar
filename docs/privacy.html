隐私政策

更新日期：2026 年 10 月 1 日

Qbar 是在 Mac 本地运行的菜单栏管理工具。当前版本没有账号、广告、分析 SDK 或后台上传服务。Qbar 不会向开发者收集或传输你的菜单栏、屏幕画面、应用列表和布局设置。

本地数据

Qbar 在本机保存菜单栏分组、快捷键、显示偏好，以及用于收纳区展示的菜单栏图标快照。普通构建使用用户目录下的 Library/Application Support/Qbar；沙盒构建使用相应的系统容器。这些文件不由 Qbar 上传。导出设置时，文件会保存到你选择的位置。

系统权限

辅助功能中的控制权限用于移动和临时显示菜单栏图标。屏幕录制权限仅用于截取菜单栏图标窗口，Qbar 不录制音频。你可以在 macOS“系统设置”中撤销权限。撤销录屏权限或重置 Qbar 设置时，应用会清除其本地图标快照缓存。

反馈

如需帮助，请到 GitHub Issues 提交问题。问题讨论是公开的，请不要上传私人截图、配置文件或诊断日志中的敏感内容。

Privacy Policy

Updated October 1, 2026

Qbar is a local macOS menu bar organizer. The current version has no account, advertising, analytics SDK, or background upload service. Qbar does not collect or transmit your menu bar, screen content, running app list, or layout preferences to its developer.

Data on your Mac

Qbar saves item groups, shortcuts, display preferences, and menu bar icon snapshots used in its tray. The regular build stores them in Library/Application Support/Qbar in your home folder; the sandbox build uses its corresponding system container. Qbar does not upload these files. An exported configuration goes only to the location you choose.

macOS permissions

Accessibility control is used to move and temporarily reveal menu bar items. Screen Recording is used only to capture menu bar icon windows; Qbar does not record audio. You can revoke permissions in macOS System Settings. Revoking Screen Recording or resetting Qbar clears the local icon snapshot cache.

Support

Use GitHub Issues for support. Issues are public; please remove private information from screenshots, configurations, and diagnostic logs before posting.
